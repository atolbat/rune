rune — демо

Живые примеры WebGL2/WebGPU-рендерера. Каждое демо — в своей папке, с мобильной вёрсткой, тумблером бэкендов и лог-панелью.

hello-cube Куб в одну строку: showAny()/showOn(), тумблер Авто/WebGL2/WebGPU, лог с копированием. model-viewer Три модели three.js examples (glTF·AVIF·Draco, FBX, normal map): кнопка загрузки с прогрессом, переключение, вращение драгом.
Локально: bun install && bun run demo → http://localhost:8080/demo/ · Список и стандарт демо — demo/README.md в репозитории.
