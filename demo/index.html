rune — demos

Live examples of the WebGL2/WebGPU renderer. Every demo lives in its own folder with a mobile-first layout, a backend toggle and a log panel.

hello-cube A cube in one line: showAny()/showOn(), an Auto/WebGL2/WebGPU toggle, a log with copy. model-viewer Three three.js example models (glTF·AVIF·Draco, FBX, normal map): a fullscreen viewer with a load button and progress bar, model switching, drag rotation. particles @rune/particles live: eight presets (fountain, fireworks, galaxy, embers, drift, snow, orbit, meteor) — a CPU-simulated SoA system baked into a billboard soup, one blended draw call, zero allocations per frame. vfx The game-VFX study on @rune/particles: 22 demos (muzzle flashes, a composed explosion, emitter shapes, trails with collision, the texture sequencer, PBR mesh particles, sub-emitters, noise, alpha-tested petals, a custom behavior, billboard modes, soft particles with a depth prepass, blend equations, a follow object, plus the rune originals — rocket, rainstorm, slash, vortex, fireflies, dust, grass, lightning) — one carousel page, ◀ ▶ or the sheet.
Locally: bun install && bun run demo → http://localhost:8080/demo/ · The demo list and standard live in demo/README.md in the repository.
