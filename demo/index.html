@rune/particles live: eight presets (fountain, fireworks, galaxy, embers, drift, snow, orbit, meteor) — a CPU-simulated SoA system baked into a billboard soup, one blended draw call, zero allocations per frame — with the CPU-tier frustum cull on every preset (the soup upload shrinks with the view) and the frame as a DECLARED GRAPH (createFrameGraph: passes with versioned resources, Pause gates the sim and the staleness counts, the HUD carries the compiled frame's own numbers).

 occlusion Hi-Z occlusion culling, GPU-driven: 16384 boxes behind a city of occluders, 51–71% never drawn, a pixel-parity gate proving the culling changes nothing — on BOTH backends.
Full history (Tasks 196–209)

WebGPU (compute + one drawIndexedIndirect) and WebGL2 (an FBO pyramid + a transform-feedback cull + a vertex-collapse draw); software adapters get the snapshot mode. Task 206 — the close-camera round: clip-space frustum counts (boxes behind the camera were drawn as «straddle») + the budgeted Greene descent in the cull kernel (the fine pass over the box's own texels): drawn 8134 → 428 at the guilty close camera, pixel parity identical on both backends. Task 207 — the same-frame feedback: the colored boxes now occlude the boxes behind them WITHIN the frame (the second field report's ask): the first cull's survivors re-render depth-only into the pyramid, it rebuilds, a second cull lands — drawn 2767 → 428 at the report's camera (exactly the brute whole-scene fill's power, at a sixth of its instance count), ON by default, declared as three frame-graph passes that die with the culling gate. Task 208 — the cross-frame seed: the bevy two-phase delta: the pyramid carries across the frame boundary as a persistent frame-graph resource (hiz-seed — the late downsample after the phase-1 depth writers is its author; the next frame's first cull reads the imported version and the staleness channel counts the lag), so the K-wall warm-up leaves the seeded frame entirely and the feedback fill's pass set collapses to exactly the final set (2767 → 428, up to ×36 less depth-only raster) while the final buckets land bit-identical — the fixed-point law, proven on both backends and under a cross-camera jump (the lag costs fill, never a pixel). Task 209 — the parallel compact + the near-first order: the last serial N-loop in the frame is gone (the flags-to-list compact runs as one 64-lane workgroup: a Hillis-Steele scan per tile + a running base produce the byte-identical ascending list), and the visible list sorts NEAR-FIRST (the cull packs a depth bucket into the verdict word's spare bits; a bitonic network orders the list by (bucket, index) — unique keys, deterministic on every backend) so the color pass's early-Z rejects the rear layers; the hysteresis fold carries the bucket, every decode masks, and the pixels are order-invariant (the gate's own proof).
